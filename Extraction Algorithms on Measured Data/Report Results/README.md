# Retained measured results

`Results_AllConfigs.csv` contains the saved v18 estimates for the 148 normal walks and ten configurations. The main report comparison uses the 142 single-pass walks. The six double walks are reported separately.

`Report_References.csv` contains the matching v17 references. The trial identifiers are P1, P2 and P3. Absolute machine paths in provenance fields have been reduced to filenames. Numerical values are unchanged.

Run `RealData_Summary_v7` from the measured-data code folder, or add that folder to the MATLAB path. No additional WAV files are needed to summarise these saved results. The function creates a new summary subfolder here. It does not rerun the extraction pipeline.
