# Measured results

`Results_AllConfigs.csv` contains the v18 estimates for 148 normal walks under ten configurations. The main analysis uses 142 single passes. Six double walks are analysed separately.

`Report_References.csv` contains the matching v17 reference values. Participants are labelled P1, P2 and P3.

Run `RealData_Summary_v7` from the measured-data folder, or add that folder to the MATLAB path. It reads these saved values and writes a summary subfolder. WAV files are not needed for this analysis.
