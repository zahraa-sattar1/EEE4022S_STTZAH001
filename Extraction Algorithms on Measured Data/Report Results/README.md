# Measured results

`Results_AllConfigs.csv` contains saved estimates for 142 single-pass walks under ten configurations. `Report_References.csv` contains the matching reference values. Participants are labelled P1, P2 and P3.

`Measured_Walks.csv` contains the 142 single-pass results used for the centroid comparison. These belong to the earlier benchmark quoted in the report.

Run `RealData_Summary_v7` from the measured-data folder, or add that folder to the MATLAB path. It reads the saved values and writes a summary subfolder. WAV files are not needed for this analysis.
