# Participant recordings

Ten radar WAV files are included: four walks from P1 and three each from P2 and P3. Files ending in `_cropped.wav` are the crops used in the analysis.

- `Demo_References.csv` lists the files, reference values, sample counts and checksums.
- `Expected_Results.csv` contains the saved estimates for comparison.

Open the repository folder in MATLAB and run:

```matlab
Run_Measured_Demo
```

The script processes all ten walks and saves the estimates and plots under `Results`. These examples are a sample of the measured dataset.
