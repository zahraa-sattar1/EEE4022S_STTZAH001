# Participant recordings

The consent forms stated that recorded data would not be shared publicly. The WAV recordings are therefore not included in the current version of this repository.

`Demo_References.csv` and `Expected_Results.csv` retain the reference values and saved estimates for the ten-walk local demonstration. They contain no recording samples. `Run_Measured_Demo` requires the matching WAV files to be supplied locally through a sharing arrangement permitted by the study consent. The files must not be added to this public repository.

The public simulation checks and analyses of saved report results do not require the WAV files.
